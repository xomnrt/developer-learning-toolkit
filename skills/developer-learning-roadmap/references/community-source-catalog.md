# Community source catalog

Checked 2026-10-28. This catalog records candidate sources supplied by the user.
Availability and licenses can change; recheck both before copying or bundling
material. Prefer linking and deriving a capability map over reproducing content.

## How to use the catalog

- Use curricula to discover sequencing and prerequisite coverage.
- Use project collections to choose practice artifacts at the right difficulty.
- Use interview repositories to generate retrieval and transfer checks after the
  capability has been taught through primary sources.
- Use handbooks and checklists as review aids. Verify technical claims through
  official documentation, specifications, or maintained source code.
- A popular repository is not automatically current, correct, or appropriate for
  the learner's target role.
- When no license is confirmed, link to the repository and do not copy, adapt, or
  bundle substantial content.

## Selection record

When a roadmap uses one of these sources, record:

```text
Source | purpose in this roadmap | sections used | checked date |
primary-source verification | license or link-only decision
```

Do not include the whole catalog in user output. Cite only sources that changed
coverage, sequencing, practice, or assessment for the current roadmap.
